# 🧭 Campus Navigator 

**Campus Navigator Pro** is a Python-based DAA mini project that finds routes between campus locations using graph algorithms.

## ✨ Features
- 🎨 Modern dark-themed Tkinter GUI
- 🗺️ Interactive campus map with highlighted routes
- ⚡ Dijkstra, BFS, and DFS algorithms
- 📊 Algorithm comparison: distance, visited nodes, and execution time
- ♿ Accessible routing option to avoid stairs
- 🔄 Swap starting and destination locations

## 🛠️ Technologies
- Python 3
- Tkinter
- Graph Data Structures
- `heapq`, `collections`, and `time`

## 🚀 How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python campus_navigator_pro.py
```

## 🧠 Algorithms
- **Dijkstra:** Finds the shortest total distance.
- **BFS:** Finds a path with the fewest edges.
- **DFS:** Explores graph branches using depth-first traversal.

## 🎓 Project Details
- **Subject:** Design and Analysis of Algorithms (DAA)
- **Language:** Python
- **Interface:** Tkinter GUI
- **Type:** Mini Project
